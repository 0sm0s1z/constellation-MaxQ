# Crew product page

Updated 2026-10-10. Crew is a native development workspace built around a project, its agent run and an explicitly attached execution environment.

## Public description

- The project owns repository context, tasks, history and retained results.
- Prime is the workspace Driver. Its intended loop is observe, plan, delegate, monitor and validate. Completion requires evidence from the assigned work.
- Agent/model selection is independent of computer selection. Constellation Router handles model routing and capacity.
- The Cua MVP targets an isolated Linux Space with terminal, files, desktop observation and input. Explicitly attached Herdr sessions are the current execution integration under development.
- Native Sessions and terminal presentation, human intervention, approvals and recovery are part of the development direction. Interactive control requires verified ownership and runtime settlement.
- Crew remains in development. Full installed-app Cua acceptance, native terminal control and end-to-end recovery are pending. Public download and onboarding remain closed.

Keep product direction separate from verified capability. The page may describe the intended workflow; screenshots must be captioned as development captures and cannot establish production readiness.
